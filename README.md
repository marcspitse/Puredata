Deze intro-les maakt jullie bekend met de programmeertaal Puredata. Dit is een visuele programmeertaal waarmee je in principe ieder denkbaar geluid op een artificiële manier kan namaken. 
Tijdens de les ga ik jullie uitleg geven over:

1 - Het programma Puredata (of de variant Plugdata)

2- Hoe je eenvoudige geluiden kan maken

3 - Hoe je "patches" van andere sound-designers kan downloaden, openen en verder bewerken.
 
Voorafgaand aan de Puredata-introductieles zorg je ervoor dat je het hebt gedownload en geïnstalleerd.
